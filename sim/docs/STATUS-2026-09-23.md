# fsae-sim status: how good is it? (2026-09-23, Simulator 0.7.1)

This is where the sim stands against the real SDM26 after the 2026-09-22 work (branch `fix/physics-review-0922`, tags `sim-v0.7.0` and `sim-v0.7.1`). The detail is in `HANDOFF-physics-2026-09-22-b.md` and `analysis-2026-09-22/`.

It now agrees with the real car everywhere there is data to check it against, except toe and roll.

## Matches real data

| What | Sim | Real / reference |
|---|---|---|
| 75 m accel | 4.45 s from the line (D.9.2.3) | 5/3 run bracketed 4.28–4.63 s; mid-range pull within ~5 % |
| Skidpad, timed figure of eight (robot) | 5.17 s, both models | Best 5.01 s; 4/23 day 5.21–5.40 s; design calculation 5.125 s |
| Ride frequency (front / rear) | 3.66 / 3.51 Hz | 3.64 / 3.48 Hz (Overall Vehicle Design Report) |
| Tyre past its peak (lock / wheelspin) | Keeps ~0.90 of peak | Team MF6.1 `.tir`: 0.96–0.98 |
| Geometry | Measured or CAD, cross-checked to 1–6 % | Rack, Ackermann, camber gain, bump steer, aero ride-height map |

## Consistent, but pinned to a single data point

- **Grip level.** Both models are pinned to the same real skidpad. Corner-by-corner grip isn't independently proven.
- **Understeer.** The car pushes at the limit, as the team says it does. The logs can't resolve the real understeer gradient; the sim is inside their scatter.

## Known disagreements

1. **Front toe.** The real toe test has a clear optimum at 1.1 deg (5.38 / 5.28 / 5.21 / 5.30 s for 0.5 / 0.8 / 1.1 / 1.4). The model says any front toe-in costs a little. This is the one real test the model gets wrong. The replication is `native/crates/sim-core/examples/toe_test.rs`.
2. **Rear toe sign.** The test data reads "−" as toe-out, per wheel. The sim runs +0.5 deg toe-in, and it matters for the 4-wheel model's high-speed stability. **Needs confirming from the setup sheet.**
3. **Roll.** Shock pots measure 0.51 / 0.64 deg/g, springs only, against the sim's 0.40 / 0.37, so the real car rolls 30–70 % more. That is about springs-only stiffness. Is it ARB lash or compliance? Unresolved; the ARB settings are unchanged per Nick.
4. **Steering force.** The real car's steering torque is about 7 N·m at the rim (design report steer-force plot, 12.5 lbf at 10 deg). The model's is roughly double before scaling, so the force feedback may be over-compressed on a 5.5 N·m R5.

## What it's good for

| Use | Rating |
|---|---|
| Course learning, lines, braking, launch technique | Very good |
| Setup direction (diff, RSD, bias, springs) | Good |
| Setup direction for toe | Not yet trustworthy |
| Absolute lap-time prediction | About ±2–4 % |
| Transient feel | Plausible, probably a bit too stiff in roll |

## To close the rest

1. **Confirm the rear toe sign** on the setup sheet.
2. **Check the anti-roll bars on the car** for lash or compliance. The bench test report exists, but no results were ever published.
3. **Log one constant-radius skidpad session** on the DAQ. Its yaw gyro works: it logs millidegrees per second.

With (1) and (3), expect lap-time prediction around ±2 %.

## Still open, not yet modelled

- Load-dependent tyre vertical rate. The report's p10 curve runs 340 lb/in light and ~527 at static.
- Roll-centre migration: about 0.1 in drop and about 220 mm/deg lateral.
- The measured damper force/velocity curve.
- Mass. Setup sheet 602 lb (~273 kg) vs the sim's 267 kg; driver-dependent.
- macOS build. The feed's macOS row is still 0.6.13, which needs a Mac to build and publish.
